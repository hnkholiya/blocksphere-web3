Web3 Fundamentals

Understand the Concepts

Compare the ideas behind Web2, Web3, blockchain networks and cryptographic ownership through simple visual explanations.

01 / INTERNET
Web2 vs Web3
WEB2

Centralized Internet

Web2 is largely built around centralized platforms and services that manage applications, data and user access.

Centralized platforms
Traditional databases
OAuth and JWT authentication
Cloud-based services
VS
WEB3

Decentralized Internet

Web3 uses blockchain networks and decentralized technologies to create new ways for users and applications to interact.

Blockchain networks
Wallet-based authentication
Smart contracts
Decentralized storage
Key Idea

Web2 generally relies on centralized services, while Web3 introduces blockchain and decentralized technologies into the application stack.

02 / BLOCKCHAINS
Bitcoin vs Ethereum
BITCOIN

Digital Money

Bitcoin introduced a decentralized system for transferring value without depending on a central financial authority.

Decentralized digital currency
Peer-to-peer value transfer
Bitcoin network
BTC is its native asset
VS
ETHEREUM

Programmable Blockchain

Ethereum extends blockchain technology with programmable smart contracts that can support decentralized applications.

Smart contracts
Decentralized applications
Programmable blockchain
ETH is its native asset
Key Idea

Bitcoin focuses strongly on decentralized value transfer, while Ethereum provides a programmable environment for smart contracts and decentralized applications.

03 / CRYPTOGRAPHY
Public Key vs Private Key
PUBLIC KEY

Shareable

A public key can be shared with others and is associated with a blockchain account or address.

Can be shared
Associated with an address
Can receive transactions
Not a secret
VS
PRIVATE KEY

Secret Credential

A private key is used to authorize transactions and prove control over blockchain assets.

Must remain secret
Authorizes transactions
Proves control of assets
Should never be shared
Key Idea

Think of the public key as something you can share, while the private key is the secret information used to authorize actions.

04 / DATA
Blockchain vs Traditional Database
BLOCKCHAIN

Distributed Ledger

A blockchain distributes control and uses cryptographic links between records to create a shared ledger.

Distributed across participants
Cryptographically linked blocks
Network consensus
Designed for verifiable history
VS
TRADITIONAL DATABASE

Centrally Managed Data

A traditional database is normally managed by an organization that controls access and modification.

Central administration
Controlled access
Authorized modification
Organization-managed infrastructure
Key Idea

The biggest difference is not simply where data is stored, but how control, verification and trust are organized.
