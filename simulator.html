What Is Happening Behind The Scenes?

The simulator uses SHA-256 hashing and repeatedly changes the nonce until the resulting hash begins with two zeroes.

01 / HASH

Cryptographic Fingerprint

Block data, previous hash and nonce are combined and processed using SHA-256.

02 / NONCE

Proof of Work

The nonce changes repeatedly until the generated hash satisfies our simplified mining condition.

03 / CHAIN

Linked Blocks

Block 2 stores Block 1's hash as its previous hash, creating the chain relationship.

CORE INSIGHT — CHAIN IMMUTABILITY

Change the data in Block 1 after mining it. Its hash changes, while Block 2 still contains the old hash as its previous hash. The chain relationship therefore becomes invalid until the affected blocks are mined again.
