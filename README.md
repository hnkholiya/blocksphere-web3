# BlockSphere

> Explore Web3. Understand Blockchain. Simulate the Chain.

BlockSphere is an educational four-page Web3 website created as part of a Web3 development assignment.

The project combines Web3 concepts, cryptocurrency market data, and an interactive blockchain mining simulator into one responsive website.

## Project Status

🚧 Development in progress.

## Planned Pages

1. Home / Landing
2. Web3 Concepts
3. Live Crypto Prices
4. Block Simulator
