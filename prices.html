Behind The Data

How Live Prices Work

This page demonstrates how a frontend application can request external Web3 data and turn the response into a useful interface.

01 / REQUEST

API Request

JavaScript sends a request to the CoinGecko public API for Bitcoin and Ethereum price information.

02 / RESPONSE

JSON Data

The API returns structured data containing current USD prices and 24-hour percentage changes.

03 / UI

Dynamic Interface

JavaScript processes the response and updates the price cards without reloading the page.

Important

Cryptocurrency prices change continuously. The values shown here represent data returned by CoinGecko when the request or widget was loaded and are not financial advice.
